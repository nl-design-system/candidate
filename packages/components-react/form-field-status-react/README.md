# Form Field Status React

A status message within a form component that provides feedback on what is going right or wrong, potentially accompanied by an action.

## Installation

Using npm

```shell
npm install @nl-design-system-candidate/form-field-status-react
```

Using pnpm

```shell
pnpm add @nl-design-system-candidate/form-field-status-react
```

Using yarn

```shell
yarn add @nl-design-system-candidate/form-field-status-react
```

## Usage

If you want the React component with styles

```jsx
import { FormFieldStatus } from '@nl-design-system-candidate/form-field-status-react/css';
```

If you just want the React component and import the styles separately

```jsx
import { FormFieldStatus } from '@nl-design-system-candidate/form-field-status-react';
```
