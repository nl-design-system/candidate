# Note CSS

Visually supportive element that draws attention to additional or important information.

## Installation

Using npm

```shell
npm install @nl-design-system-candidate/note-css
```

Using pnpm

```shell
pnpm add @nl-design-system-candidate/note-css
```

Using yarn

```shell
yarn add @nl-design-system-candidate/note-css
```

You can import the CSS directly from a CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@nl-design-system-candidate/note-css/dist/note.css"
/>
```

You can import the CSS directly from the `node_modules/`

```html
<link rel="stylesheet" href="node_modules/@nl-design-system-candidate/note-css/dist/note.css" />
```

You can import the CSS from JavaScript

```js
import '@nl-design-system-candidate/note-css/dist/note.css';
```

## Design Tokens

All NL Design System components are white label. Use Note design tokens to ensure it matches your brand styles. [https://nldesignsystem.nl/handboek/huisstijl/design-tokens/](https://nldesignsystem.nl/handboek/huisstijl/design-tokens/).

See [nldesignsystem.nl/note/#design-tokens](https://nldesignsystem.nl/note/#design-tokens) for a full overview. These tokens can be found in the tokens documentation [@nl-design-system-candidate/note-tokens](https://www.npmjs.com/package/@nl-design-system-candidate/note-tokens).
