# Text Area CSS

Input field for editing multiple lines of text.

## Installation

Using npm

```shell
npm install @nl-design-system-candidate/text-area-css
```

Using pnpm

```shell
pnpm add @nl-design-system-candidate/text-area-css
```

Using yarn

```shell
yarn add @nl-design-system-candidate/text-area-css
```

You can import the CSS directly from a CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@nl-design-system-candidate/text-area-css/dist/text-area.css"
/>
```

You can import the CSS directly from the `node_modules/`

```html
<link rel="stylesheet" href="node_modules/@nl-design-system-candidate/text-area-css/dist/text-area.css" />
```

You can import the CSS from JavaScript

```js
import '@nl-design-system-candidate/text-area-css/dist/text-area.css';
```

## Design Tokens

All NL Design System components are white label. Use Text Area design tokens to ensure it matches your brand styles. For more information about design tokens, see
[https://nldesignsystem.nl/handboek/huisstijl/design-tokens/](https://nldesignsystem.nl/handboek/huisstijl/design-tokens/).

See [nldesignsystem.nl/text-area/#design-tokens](https://nldesignsystem.nl/text-area/#design-tokens) for a full overview of the Text Area tokens. These tokens can be found in the tokens package [`@nl-design-system-candidate/text-area-tokens`](https://www.npmjs.com/package/@nl-design-system-candidate/text-area-tokens).

## Other implementations

Want to use Text Area with React? Follow the instructions described in the React package
[`@nl-design-system-candidate/text-area-react`](https://www.npmjs.com/package/@nl-design-system-candidate/text-area-react).

Want to use Text Area with other frameworks or vanilla JavaScript? The React component is based on the CSS package
[`@nl-design-system-candidate/text-area-css`](https://www.npmjs.com/package/@nl-design-system-candidate/text-area-css).
