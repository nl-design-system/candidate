# Form Field Status CSS

A status message within a form component that provides feedback on what is going right or wrong, potentially accompanied by an action.

## Installation

Using npm

```shell
npm install @nl-design-system-candidate/form-field-status-css
```

Using pnpm

```shell
pnpm add @nl-design-system-candidate/form-field-status-css
```

Using yarn

```shell
yarn add @nl-design-system-candidate/form-field-status-css
```

You can import the CSS directly from a CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@nl-design-system-candidate/form-field-status-css/dist/form-field-status.css"
/>
```

You can import the CSS directly from the `node_modules/`

```html
<link
  rel="stylesheet"
  href="node_modules/@nl-design-system-candidate/form-field-status-css/dist/form-field-status.css"
/>
```

You can import the CSS from JavaScript

```js
import '@nl-design-system-candidate/form-field-status-css/dist/form-field-status.css';
```

## Design Tokens

All NL Design System components are white label. Use Form Field Status design tokens to ensure it matches your brand styles. For more information about design tokens, see
[https://nldesignsystem.nl/handboek/huisstijl/design-tokens/](https://nldesignsystem.nl/handboek/huisstijl/design-tokens/).

See [nldesignsystem.nl/form-field-status/#design-tokens](https://nldesignsystem.nl/form-field-status/#design-tokens) for a full overview of the Form Field Status tokens. These tokens can be found in the tokens package [`@nl-design-system-candidate/form-field-status-tokens`](https://www.npmjs.com/package/@nl-design-system-candidate/form-field-status-tokens).
